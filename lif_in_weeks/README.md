🗓️ Life in Weeks
📖 Problem Statement

Create a function named life_in_weeks(age) that calculates how many weeks a person has left if they live until 90 years old.

The function should:

Accept the current age as an argument.
Calculate the remaining weeks until age 90.
Print the result in the following format:
You have x weeks left.

Where x is the calculated number of weeks remaining.
