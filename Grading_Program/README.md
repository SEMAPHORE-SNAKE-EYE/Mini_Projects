# Grading Program

## Description

This Python program converts student exam scores into grades based on predefined criteria.

## Grading Criteria

* 91 - 100 → Outstanding
* 81 - 90 → Exceeds Expectations
* 71 - 80 → Acceptable
* 70 or below → Fail

## Input

```python
student_scores = {
    'Harry': 88,
    'Ron': 78,
    'Hermione': 95,
    'Draco': 75,
    'Neville': 60
}
```

## Output

```python
{
    'Harry': 'Exceeds Expectations',
    'Ron': 'Acceptable',
    'Hermione': 'Outstanding',
    'Draco': 'Acceptable',
    'Neville': 'Fail'
}
```

## Concepts Used

* Python Dictionaries
* for Loops
* Conditional Statements (if-elif-else)
* Dictionary Manipulation
